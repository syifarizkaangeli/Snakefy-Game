# Snakefy

Snakefy is a modern recreation of the classic Snake arcade game built with Python and Pygame. Players control a growing snake, collect food, increase their score, and avoid collisions while aiming to achieve the highest score possible.

## Features

* Modern neon-inspired user interface
* Smooth snake movement with keyboard controls
* Animated food with pulse effect
* Dynamic difficulty scaling based on score
* Real-time score tracking
* Persistent high score system
* Self-collision detection
* Wall collision detection
* Start screen interface
* Game Over screen with restart functionality
* Achievement progression system
* Responsive grid-based gameplay
* Clean and modular project structure

## Technologies Used

* Python 3
* Pygame 2.6.1
* Object-Oriented Programming (OOP)
* File Handling for High Score Persistence
* Modular Python Architecture

## Controls

* ↑ Move Up
* ↓ Move Down
* ← Move Left
* → Move Right
* Space — Start Game
* R — Restart Game
